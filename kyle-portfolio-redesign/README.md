# Kyle Bailey Portfolio Redesign

This is a complete visual redesign of the portfolio.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive visual system
- `script.js` — mobile navigation + scroll reveal

## Assets
Copy your existing `Assets` folder next to `index.html`, including:
- `Headshot-fullsize.jpg`
- `BodyCompLogo.png`
- `vibelogo.png`

The design intentionally keeps the portfolio dependency-light: plain HTML/CSS/JS plus Google Fonts.

## Main design changes
- Fixed glass navigation
- Large editorial hero section
- Strong typography hierarchy
- Developer/code visual
- Featured project grid
- Timeline-style experience
- Skills/about section
- Education card
- High-contrast contact CTA
- Mobile navigation
- Scroll reveal animations
